# Project 42 Field Guide 0.6.2

This release packages the Field Guide as a versioned static archive with
release facts, checksums, a strict manifest, and provenance.

## Breaking changes

None. Existing guide routes and GitHub Pages deployment behavior are preserved.

## Migrations

No data or configuration migration is required.

## Known limitations

The archive is a static reference site. Hosted learner identity, progress, and
assessment services are provided separately by Project 42 Learn.

## Rollback

Redeploy the preceding known-good Pages artifact or prior signed static archive.
No learner records are modified by this release.
